# QuickDeck Internationalization (i18n)

## Supported Languages

| Code | UI Label |
|------|----------|
| `en` | English |
| `zh_CN` | 简体中文 |

## Architecture

```
settings.general.language  →  LocaleService  →  QTranslator (:/i18n/*.qm)
                                              →  QQmlApplicationEngine::retranslate()
                                              →  Widgets via QEvent::LanguageChange
```

- **C++ strings**: `tr()` in widgets/services; contexts in `translations/quickdeck_*.ts`
- **QML strings**: `qsTr()` in overlay/components; same TS files via `qt_add_translations`
- **Persistence**: `settings.general.language` (string key, no schema migration required)
- **Default**: system locale (`zh_CN` if Chinese, otherwise `en`)

## Switching Language

1. Open **Settings → General → Language**
2. Save — overlay retranslates immediately; widgets/tray update via signals

## Adding a Language

1. Copy `translations/quickdeck_en.ts` → `translations/quickdeck_xx.ts`
2. Add to `CMakeLists.txt` `qt_add_translations(TS_FILES ...)`
3. Extend `LocaleService::supported_languages()` and `display_name()`

## Build

Translations compile to `:/i18n/quickdeck_<locale>.qm` at build time via `qt_add_translations`.

To refresh TS from sources (developer machine):

```bash
lupdate -locations none -no-obsolete CMakeLists.txt src/ translations/
lrelease translations/quickdeck_en.ts translations/quickdeck_zh_CN.ts
```
